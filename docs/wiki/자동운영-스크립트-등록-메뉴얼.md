해당페이지는 운영 스크립트를 등록하여, 자동화하는 것을 알려드리기 위한 메뉴얼 페이지 입니다  
## 스크립트 등록하기.
1.automation탭으로 들어가게 되면 아래와 같이 서버에 등록되어진 스크립트가 보여지게 됩니다. 이곳에서 scriptlist를 클릭합니다.
![title](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-20180328-git-ScriptUploadMenual01.PNG)  
2.다음과 같이 리스트가 보여집니다. 이 페이지에서 add script를 클릭합니다.
![title](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-20180328-git-ScriptUploadMenual02.PNG)
3.아래와 같은 페이지 양식에 맞춰서 글을 작성하도록 합니다. (운영 인프라에 등록된 스크립트를 사용하실 경우에는 이름과 내용을 크게 수정하지 않는 선에서 변경하시길 권장합니다.)
![title](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-20180328-git-ScriptUploadMenual03.PNG)
4.적용 후에, script list를 확인하시게 되면, script가 등록이 되어진것을 확인 할 수 있습니다. 해당 스크립트를 등록하기 위해, Que management탭으로 들어갑니다. 
![title](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-20180328-git-ScriptUploadMenual04.PNG)
5.현재 서버에 등록이 되어진 스크립트들을 확인 할 수 있습니다. add que버튼을 눌러 만든 스크립트를 등록합니다.
![title](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-20180328-git-ScriptUploadMenual05.PNG)
6.스크립트를 서버에 등록하기 전, 옵션을 직접 세팅하여 등록 할 수 있습니다. 아래 페이지 안에서 자신이 등록한 스크립트의 성격에 맞게
설정내용을 커스텀하여 등록하도록 합니다.
![title](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-20180328-git-ScriptUploadMenual06.PNG)
