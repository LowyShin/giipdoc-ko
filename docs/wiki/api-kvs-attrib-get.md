# KVS Attrib

- uri
  - api/kvs/attrib/get
- method
  - GET/POST
- input
  - sk `-- Secret Key`
  - ktype `-- lssn 고정`
  - kkey `-- lssn값(Logical Machine의 SN)`
  - kFactor `-- KVS에 사용된 Factor`
  - kAttrib `-- KVS에 사용된 Attrib`
  - otype `-- output형식, morris, json`
- output
  - otype에 맞는 형식으로 출력
