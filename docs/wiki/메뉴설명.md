# giip 소개

giip 사용자 login 계정 정보를 Google API 모듈을 연동 하여 인증을 처리 합니다. 만약, 외부 망을 전혀 사용 하지 않는 곳에서의 설치 라면, 자체 Login을 기능을 활용하여 계정 관리를 할 수 있습니다. 본 장에서는 giip를 활용한 정책 및 환경 설정을 간단하게 할 수 있게 대강의 기능을 설명하고 자세한 설명은 다음 장부터 시작 됩니다. giip의 주요 기능은 아래와 같습니다. 

### DASH BOARD
### LOGICAL SERVER
### DOMAIN MANAGE
### SERVICE PROVIDER
### USER MANAGE
### SECRET KEY
### AUTOMATION


***


다음의 그림들은 giip의 각 화면에 대한 소개입니다
Dash Board는 매 30초 마다 갱신되며, 고객의 요청에 따라 다양한 정보로 교체가 가능합니다. 다음은 giip의 ‘Dash Board' 화면입니다.

![Dash Board](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-manual-01menu-dashboard.png)

**1. Customers:**  커스터머 정보 표시. 현재 관리되고 있는 커스터머 수와 최근 정보가 갱신된 커스터머 정보를 5개까지 표시하여 나타내어줍니다.  타이틀 버튼(Customers)을 클릭하면 관리페이지로 넘어가게 되고, 리스트에 나와있는 정보를 누르면 해당 커스터머 관리 페이지로 넘어가게 됩니다.

**2. Servers:** 관리중인 장비의 정보 표시. 현재 관리중인 커스터머의 모든 장비의 수량이 표시 되고, 최근 정보가 갱신된 5개의 장비를 보여줍니다. 타이틀 버튼(Servers)을 누르면 등록된 논리서버 리스트로 이동하게 되고, 리스트에 나와 있는 메시지 정보를 클릭하면, 해당 장비의 상세 페이지로 넘어가게 됩니다

**3. Warning Messages:** 경고 메시지 현황. 금일 0시0분이후 발생한 경고 메시지의 개수를 표시하고, 최근 발생한 경고 리스트를 5개까지 나타내어 줍니다. 타이틀 버튼(Warning Messages)를 클릭하면 경고 관리 리스트로 넘어가고, 리스트를 클릭하면 클릭 된 경고 메시지의 상세정보를 볼 수 있는 페이지로 이동을 하게 됩니다.

**4. Working jobs:** 자동화 작업 현황. 현재 가동중인 자동화 작업의 숫자가 표시 되고,최근 실행된 자동화 작업을 5개까지 나타내어 줍니다. 타이틀 버튼(Working jobs)을 클릭하면 자동화 관리리스트로 이동하게 되고, 리스트를 클릭하게 되면 자동화 작업 현황으로 이동 하게 됩니다.

**5. Statistics logical Server:** 이력을 나타내어줍니다. 현재 실행된 자동화 작업을 이용해 서버의 상태, 트리거 횟수, 현재 수행하는 작업의 숫자를 표시합니다.

**6. Messages:** 메세지표시. 설정된 메시지를 표시합니다. 관리자가 지정한 경고나 업무 작업에 대한 수행한 메시지를 customer별로 표시합니다.

Dash Board 에서 다음 화면으로 넘어가면 (아무 버튼을 클릭했을 경우 넘어가게 됩니다.) 상단에 메인 메뉴가 나타나게 됩니다.

다음은 giip의 ‘메인 관리’ 화면입니다.

![Menu Icon](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-manual-01menu-icon.png)

**1. Logical Server List로 이동:**  등록 된 Logical Server 로 이동하게 됩니다.

**2. Domain List로 이동:** 도메인 관리 리스트로 이동하게 됩니다.

**3. Service Provider (IDC) List로 이동:** 실제적으로 사용하는 장비의 위치IDC 및 서비스 받고 있는 Cloud를 등록 할 수 있는 페이지로 이동하게 됩니다.

**4. Customer List로 이동:** 고객(커스터머) 리스트로 커스터머를 등록 할  수 있는 페이지로 이동하게 됩니다.

**5.  UserList 로 이동:** 사용자 관리 페이지로 이동하게 됩니다.

**6.  Service & Secret Key List 로 이동:** Secret Key 관리페이지로 이동하게 됩니다. 

(Secret Key 관리란 서비스 그룹별 관리를 뜻합니다.)

**7. Que List로 이동:** Automation을 위한 Script를 관리 할 수 있는 페이지로 이동 하게 됩니다.
