## 시작하며

가급적 쉽게 설명하도록 하고 있으나, 
이해가 가지 않는다면 언제든 문의하기를 눌러서 문의해 주시기 바랍니다. 
문의 내용을 지속적으로 업데이트 해놓겠습니다. 

giip는 RESTful API를 이용하여 통신하고 있습니다. 
값을 던질때는 GET/POST 모두 사용 가능하고, 
값을 받을 때는 JSON을 이용하여 텍스트 타입으로 받습니다. 

받은 JSON에 공개되어 있는 소스 및 라이브러리를 활용하면 관리툴도 직접 만들 수 있습니다. 
자신의 개발 툴이기 때문에 인증 처리는 직접 만들어야 하고, 인증에 맞추어 Secret Key를 할당하는 룰을 직접 만들어야 합니다. 
예제에서는 자신만의 툴이기 때문에 인증은 생략하고 만들도록 하겠습니다.
