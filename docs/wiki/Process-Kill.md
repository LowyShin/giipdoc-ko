예제 소스 : https://github.com/LowyShin/giip/blob/gh-pages/giipscripts/ps1/ProcessKill.ps1

예제에서는 notepad라는 프로세스를 찾아서 삭제하라는 명령입니다. 
giip Automation Script에 예제를 등록후
적용할 서버의 상세 정보에서 Add Queue를 하거나 Automation의 아래쪽 Add Queue Group 을 눌러 서비스 그룹단위로 한 번에 적용할 수 있습니다. 
Add Queue 화면에서 CustomVariables 라는 항목은 소스 아래쪽의 CustomVariables 영역을 복사해서 붙여 넣은 뒤에 프로세스 명을 임의로 지정할 수 있습니다. 
만약 여러 개의 프로세스를 삭제 해야 한다면 소스를 개조할 필요는 있습니다. ^^
이 소스를 활용한다면 현재 떠있는 프로세스 외의 프로세스도 찾을 수 있겠지요?
