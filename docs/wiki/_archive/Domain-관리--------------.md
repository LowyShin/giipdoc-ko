## 도메인 관리(DOMAIN MANAGE)

도메인 관리 기능은 서비스 사용자가 자신의 도메인 등록기관과 만료 날짜를 인지하지 못하여 발생 하는 장애에 대하여 기록하고 관리 함으로써 사전 예방의 의미로 사용 하는 탭입니다.

아래 그림은 DOMAIN MANAGE 의 각 기능별 설명입니다.

![service-domain](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-manual-04service-domain01.png)


위 화면에서 Add Domain를 눌러 도메인과 등록 기간을 설정합니다.

![service-domain](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-manual-04service-domain02.png)


**1. Domain Name:** 도메인 명 기제

**2. Register Domain Provider:** 도메인 등록기관

**3. Management URL:** 도메인 관리 URL

**4. Insert record:** 저장

 위 그림의 내용을 등록하면 아래 그림처럼 저장 된 내용이 보여집니다.

![service-domain](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-manual-04service-domain03.png)


1. 도메인 상세 정보 화면으로 이동

2. refresh from internic: 도메인 만료일 정보 자동 취득

3. 도메인 관리 사이트 이동

4. 신규 도메인 등록

 
위 그림에서 **“1”** 을 눌러 들어가게 되면 해당 도메인에 대하여 수정이나 삭제가 가능합니다.
 
아래 그림은 **“1”** 을 눌렀을 때의 화면입니다.
