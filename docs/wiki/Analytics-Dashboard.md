## Analytics Dashboard
Anayltics Dashboard 페이지는 시스템 내에서 연결된 다른 머신들의 실시간 모니터링을 해주는 페이지 입니다. (1분마다 갱신)

![image](https://github.com/user-attachments/assets/5822e395-5943-4d2b-9adb-5d117ac51212)

- 프로젝트 수
- 작동중인 머신 수
- 작업 중인 머신 수
- 절감된 시간
### RPA(Robotic Process Automation) 등급 :  
 작동중이나 작업중인 컴퓨터, 프로젝트 수에 따라 색이 바뀝니다. 

1단계 : RPA begginer.  
2단계 : Bronze rank of RPA.  
3단계 : Gold rank of RPA.  
4단계 : Master of RPA!  
5단계 : RPA Challenger !!
