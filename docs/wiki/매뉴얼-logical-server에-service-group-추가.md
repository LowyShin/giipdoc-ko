## Logical Server에 Service Group 추가

* 전제 사항
  * Logical Server 추가 완료
    * Logical Server가 추가가 안된 경우 먼저 추가해주세요. 
    * [[매뉴얼 - Logical Server 추가]]
  * Service Group 추가 완료
    * Service Group이 추가가 안된 경우 먼저 추가해주세요. 
    * [[매뉴얼 - Service Group 추가]]

## 작업 순서

1. Logical Server의 [Modify] 버튼 클릭
2. Service Group 풀다운 메뉴에서 Service Group 선택
  - Service Group을 생성했는데 보이지 않는 경우 상단의 Customer 풀다운 메뉴에서 Service Group을 생성한 Customer를 선택하였는지 확인합니다.
3. [Save] 버튼 클릭
