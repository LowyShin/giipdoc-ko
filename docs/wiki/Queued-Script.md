## Automation Queued Script
작업 대기중인 스크립트들을 나타내는 위치입니다.


### 작업 대기열에 올리는 방법

![image](https://github.com/user-attachments/assets/b7cd5d23-dd79-4661-ab82-45b8b4969ea8)

Script Repository의 만들어놓은 스크립트의 msName부분을 클릭합니다. (스크립트 만드는 법은 [[Script-Repository]] 참조)

![スクリーンショット 2025-05-11 160849](https://github.com/user-attachments/assets/beeb86e3-9ebd-4bcf-a52e-9772957ffbda)

1. 등록된 서버들 중 실행하고 싶은 서버에 체크합니다.
2. 작업을 반복하고 싶다면 3번의 반복 여부 체크박스를 yes로 바꾼 후 반복 시간을 입력합니다(시간단위 : min).
4. 5번의 시작 여부 체크박스를 yes로 바꾼 후 시작 일자를 입력합니다.
6. 추가로 입력하고 싶은 명령어나 스크립트를 입력합니다.
7. 실행자명을 입력합니다.
