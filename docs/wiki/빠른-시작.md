giip agent를 설치하기위한 과정을 간략히 정리한 글입니다.


giip는 다양한 RPA를 통합관리하는 서비스입니다.


얼핏 보면 길어보이지만, 익숙해지면 서버를 등록하고 감시설정을 하는데 1분도 걸리지 않게 됩니다. 


우선 첫 로그인에서부터 서버의 상태를 보여주는 간단한 순서를 적어봅니다. (CentOS를 기준으로 작성합니다. 다른 OS는 각각의 OS에 맞도록 조정하시기 바랍니다.)


### 새로운 계정을 생성하여 로그인합니다.

### Project 생성

- 로그인 되었으면 Dashboard가 표시될 것입니다. 왼쪽 메뉴에서 Environment를 클릭하고 Projects를 클릭하여 들어갑니다.

![image](https://github.com/LowyShin/giipdoc-ko/assets/20239203/b6daec06-067f-41e9-8122-d192b0808825)

* Project를 생성합니다.

![quickstart-03addcustomer](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-2018-quickstart-03addcustomer.png)

- 프로젝트 코드와 이름을 적어주면 바로 생성이 됩니다. 프로젝트 코드는 너무 길면 잘리는 경우가 많아 축약형 표시로 사용 됩니다. 

![image](https://github.com/LowyShin/giipdoc-ko/assets/20239203/c41ab5cb-4c83-4347-8626-44d49520daaa)


상단의 풀다운 메뉴에서 생성한 Project를 선택합니다. 

프로젝트 단위로 관리 되기 때문에 프로젝트를 변경할 때마다 전체 환경이 변경됩니다. 참고로 Script는 프로젝트와 관계 없이 어카운트 베이스로 재활용할 수 있습니다. 

![quickstart-04customerselect](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-2018-quickstart-04customerselect.png)

* Project 화면의 좌측 메뉴에서 Environment에서 Services를 클릭하여 Service를 추가합니다.

![quickstart-05Service](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-2018-quickstart-05Service.png)

서비스 역시 프로젝트와 마찬가지로 서비스코드와 설명만 넣으면 되는데, 생성후에 반드시 해야할 일이 있습니다.


생성된 Service 옆에 [Create Key] 버튼을 클릭하여 Secret Key를 생성합니다. 이 Secret Key는 서버와 giip가 통신할 때 사용하는 인증 수단입니다.
Secret Key가 없으면 서버를 제어할 수 없게 되기 때문에 반드시 생성을 해주셔야 하구요, Secret Key는 서비스 단위로 통합 관리를 하게 됩니다. 만약 Secret Key가 유출 된 것 같다고 생각되면 Secret Key를 Renew를 눌러 바꾸시면 그 동안 사용하였던 인스턴스들의 Secret Key가 맞지 않아 제어가 멈춤니다. 위급한 상황에서만 해주셔야 하구요, 한 번 Renew를 해버리면 되돌릴 수 없으니 신중하게 하셔야 합니다. 

만약 Renew로 이 서비스의 모든 인스턴스 제어가 멈추었다면 각 인스턴스에 들어가서 새로운 Secret Key를 넣어주셔야 합니다.

### 서버 작업

* 서버에 터미널 접속을 합니다. (커맨드가 사용 가능한 상태 및 root권한을 가지고 있는 상태여야 함.)

1. sudo su를 사용하여 root권한으로 합니다. (root가 아니어도 괜찮지만, 권한이 부족하면 그에 따라 실행이 안되는 부분이 발생합니다.)

2. 터미널 상태에서 giip agent파일을 놔둘 위치로 이동합니다. 

3. 파일을 놔둘 위치에서 git clone을 실행합니다. 
   - `git clone https://github.com/LowyShin/giipAgentLinux.git`

4. 생성된 디렉토리에 들어가지 말고 하나 밖에서 설정용 파일을 복사해 옵니다. 
   - `cp giipAgentLinux/giipAgent.cnf ./`

5. 복사한 설정 파일에 Web UI에서 설정한 값들을 맞춥니다. 
   - `vi giipAgent.cnf`
   - sk와 lssn을 웹 화면에 있는 내용으로 바꾸고 저장합니다.  
   ![giipAgent.cnf](https://github.com/LowyShin/giipdoc-ko/assets/20239203/49c764d5-2d44-45f2-9be8-4bc3ff7aa1b6)
   ![image](https://github.com/LowyShin/giipdoc-ko/assets/20239203/c966ede2-2d43-4134-aec8-b17c296d1a7d)

6. giipAgentLinux 디렉토리로 이동합니다. 
   - `cd giipAgentLinux`

7. 윈도우즈 OS에서 만든 파일의 경우 crlf등의 처리가 자연스럽지 않은 경우가 있으므로 dos2unix라는 툴을 설치합니다.
   - `yum install -y dos2unix`

8. cron에 올립니다.
   - `sh giipcronreg.sh`

이렇게 하면 giip와 서버는 연결을 시작합니다. 

### 서버 정보 취득 스크립트의 등록

* giip 좌측메뉴에서 Automation의 Script Repository를 클릭하여 Automation관리화면으로 이동합니다.

![quickstart-13AddScript](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-2018-quickstart-13AddScript.png)

* Add Script 버튼을 클릭하여 아래 스크립트를 복사하여 넣습니다. 

  https://github.com/LowyShin/giip/blob/gh-pages/giipscripts/sh/getSystemInfoLinux_v02.sh

* 제목은 적당히 [시스템 정보 취득] 등의 알아보기 쉬운 이름을 적고, 설명 부분을 적고 스크립트 타입은 sh를 선택하고 저장합니다. 
* 나머지는 아직 기능하지 않습니다. 

![quickstart-15Scriptsave](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-2018-quickstart-15Scriptsave.png)

* 좌측 메뉴의 Automation 의 Script Repository를  다시 클릭해서 방금 생성한 스크립트 이름을 클릭합니다. 

![quickstart-16AddQueue](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-2018-quickstart-16AddQueue.png)

* 하단으로 스크롤하여 Add Queue로 이동한후 생성한 스크립트와 실행하고자 하는 서버에 체크박스를 체크하고 주기를 선택(기본5분)하고 Apply Queue버튼을 클릭합니다.

![quickstart-17QueueApply](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/giip-ko-2018-quickstart-17QueueApply.png)

이렇게 설정하면 설정한 주기 후에 서버는 위의 시스템 정보 취득 스크립트를 가져와서 실행하게 되고, 서버 상세에는 기본적인 정보가 표시되게 됩니다.
바로 알고 싶다면 QUeued Servers라는 곳에 방금 등록한 서버가 표시되는데 거기서 삼각형 플레이 버튼을 누르면 다음 주기에 바로 실행되게 됩니다.
