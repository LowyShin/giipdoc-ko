예제 소스 : https://github.com/LowyShin/giip/blob/gh-pages/giipscripts/sh/getSystemInfoLinux.sh

giip에 등록되어진 서버에 대한 서버 정보들을 불러옵니다. 불러오는 정보들은 다음과 같습니다.
- hostname
- cpuname
- OSver
- mem
- cpunum
- CPU Usage

![topmenu](https://github.com/LowyShin/giip-ko/blob/gh-pages/images/메뉴바.PNG)


해당 스크립트가 실행이 되면 아래와 같이 Logical Server Information 파트에 서버에 대한 사양정보를 가져오게 됩니다.
(! 해당 정보들은 명령어를 통해 가져오는 스크립트입니다. 따라서 버젼에 따라 가져오지 못하는 경우가 있을 수 있기에 소스의 수정이 필요합니다.)
