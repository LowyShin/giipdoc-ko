## Logical Server 추가 매뉴얼

Logical Server는 Physical Machine 위에 올라간 OS를 뜻합니다. 
x86의 Hypervisor기술및 UNIX의 P-PAR, L-PAR기술을 이용하여 하나의 머신 내에 가상머신(VM, Virtual Machine)이 있을 수 있기 때문에 giip에서는 OS단위를 Logical Server라고 지칭합니다.

추가 순서

1. 상단 메뉴에서 Logical Server 아이콘을 클릭
2. 서버 리스트 화면에서 [Add Logical Server] 버튼을 클릭
3. 서버 추가 화면에서 정보 입력
 * Label : 추가하고 싶은 서버의 라벨을 입력
 * Service Group : [Secret Key] 관리 페이지에서 추가한 Service Group을 선택
4. [Save] 버튼을 클릭
