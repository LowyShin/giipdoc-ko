## 스크립트 추가하기

Add Script를 클릭합니다.

![スクリーンショット 2025-05-11 151427](https://github.com/user-attachments/assets/e92575eb-4866-44fc-9db2-00478369cce3)

1. script 이름 작성
2. 파일 형식 선택
3. 간단 설명 작성
4. 소스(명령어) 넣기

이후, 저장을 누르면 완료!

![image](https://github.com/user-attachments/assets/7a7abe0d-868d-4f76-8a7a-43d3f6251547)

- ms Sn : Microsoft Script Number 작성한 스크립트의 번호를 보여줍니다.
- ms Name : Microsoft Name 작성한 스크립트의 이름을 보여줍니다.
- ms Regdt : Microsoft Registered date 스크립트의 등록된 날짜를 보여줍니다.
- ms Type : Microsoft Type 스크립트의 내용을 보여줍니다.
