## GIIP — 한눈에 진단하고, 바로 조치하는 운영 플랫폼

데이터베이스 성능 분석, 멀티클라우드 모니터링, 원격 자동화까지 하나의 대시보드에서 끝냅니다. 문제를 찾고 해결하는 시간을 눈에 띄게 줄여 보세요.

- 바로 체험: https://giipv3.vercel.app
	- 한국어: https://giipv3.vercel.app/ko
	- English: https://giipv3.vercel.app/en

### 이런 분께 추천합니다
- DB와 서비스 상태를 한 화면에서 보고, 바로 조치까지 하고 싶은 운영/개발자
- AWS·Azure·온프렘을 함께 쓰는 멀티 클라우드 환경의 관리자
- 에이전트 기반의 가벼운 원격 자동화와 대량 커맨드 배포가 필요한 팀

### 핵심 기능
- SQL3D: 쿼리 실행 이력/분포/그룹을 기반으로 병목 지점 시각화
- KVS 도구: 키/값 검색·대량 삽입/삭제·최신값 조회 등 실무형 유틸리티
- 서비스 점검·원격 실행: LSVR 검증, 원격 명령 전송/결과 수집
- 전송량/네트워크 가시화: 요청별 송수신 바이트 집계로 비용·병목 파악

### 3분 만에 시작하기
1) 웹 접속 후 로그인/회원가입
2) 프로젝트 생성 후 기본 대시보드 확인
3) 필요한 경우 에이전트를 설치해 원격 명령/자동화를 활성화
	 - 자세한 안내: 빠른 시작(한글 위키) → https://github.com/LowyShin/giipdoc-ko/wiki/%EB%B9%A0%EB%A5%B8-%EC%8B%9C%EC%9E%91

### 사용 사례
- 멀티 클라우드 자원과 사내 서버를 한곳에서 모니터링하고 제어
- 수십~수백 대 서버에 안전하게 커맨드를 배포하고 결과를 KVS로 수집
- 무거운 CI/CD 없이, 가벼운 원격 자동화로 배포·점검·롤백 수행
